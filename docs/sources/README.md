# Collection references

Catalog labels are conservative lower bounds with a plus sign. They describe the source collections. The page keeps LibriVox primary; Lit2Go and Wolne Lektury are additional audiobook catalogs, and Gutenberg supplies linked book texts. Native catalog availability is documented in the current app source.

Figures checked October 13, 2026:

- LibriVox: 21,000+ completed projects and 49 catalog languages. https://librivox.org/ and https://librivox.org/2026/09/16/librivox-api-update/
- Lit2Go: hundreds of audio titles; English. https://etc.usf.edu/lit2go/giving/ and https://fcit.usf.edu/audiobooks-for-english-language-learners/
- Project Gutenberg: 75,000+ ebooks, with multiple languages. https://www.gutenberg.org/about/ and https://www.gutenberg.org/browse/languages/
- Wolne Lektury: 7,000+ works, 1,000+ audiobooks. https://wolnelektury.pl/info/o-projekcie/
