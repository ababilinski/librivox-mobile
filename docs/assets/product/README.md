# Website artwork

Run `python3 scripts/generate-site-assets.py` from the repository root.

The book-cover SVGs are original geometric illustrations and typesetting created for this website, licensed under this repository's MIT license. They illustrate the works, rather than reproduce a particular audiobook edition's cover. Work references are linked in `manifest.json` and on the website.

App screen images are proportional WebP derivatives of the authentic October 8 release captures. Screens are not cropped, repainted, or altered. Their source paths, source hashes, output hashes, and dimensions are recorded in `manifest.json`. The capture manifest next to the original PNGs describes the release emulator captures and the physical-device Cast capture. Embedded artwork and third-party UI remain subject to their source rights; the software license does not grant rights to audiobook content.

The app icon is resized from the published project icon. The social card is an original typographic composition. No remote font, image, audio, or catalog request is needed to render the website.
